# WaterHub — Telegram-бот підбору систем + замовлення в KeyCRM

Менеджер надсилає боту показники клієнта (аналіз води, кількість мешканців і санвузлів, контакти).
Бот підбирає систему водопідготовки з каталогу WaterHub і створює замовлення в KeyCRM.

## Як працює

**Варіант 1. Повідомлення в чат** (швидко, з телефона):

```
Свердловина, Fe 2.5, Mn 0.3, жорсткість 9, pH 7.1, амоній 0.8, 4 людини, 2 санвузли, преміум
Клієнт: Іван Петренко, +380671234567
Місто: Буча
```

Бот відповідає ступенями системи, специфікацією з цінами й кнопками:
- **✅ Створити замовлення в KeyCRM** — з'являється, коли є ПІБ, телефон і всі ціни;
- **📝 Відкрити форму** — Mini App із уже заповненими даними.

Розуміє українські й російські назви: Fe/залізо/железо, Mn/марганець, жорсткість/жесткость, pH, окиснюваність, амоній, нітрати, каламутність, кольоровість, сірководень, хлор.

**Варіант 2. Mini App (форма)** — кнопка «Підбір системи» в меню бота.
Підбір перераховується наживо, специфікацію можна редагувати (кількість, ціна, додати позицію з каталогу).
Кнопка Telegram «Створити замовлення в KeyCRM» надсилає замовлення.

## Логіка підбору (`lib/selector.js`)

| Умова | Ступінь | Клапан масовий / преміум | Засипка |
|---|---|---|---|
| Каламутність > 2 NTU | Освітлення | Runxin F67C1 / Clack CI | Raifil Filter AG |
| Міська вода з хлором | Сорбція | F67C1 / Clack CI | Ecocarb 8×30 |
| Fe > 5, Mn > 1, H₂S **або** лише Fe/Mn | Безреагентне знезалізнення | F67C1 (Clack TC при Fe > 3, Mn > 0,5, H₂S) / Clack TC | Katalox Light / XaiR |
| Жорсткість > 3,5 без Fe/амонію/органіки | Пом'якшення | Runxin F63C3 / Clack CI | Raifil C100E |
| Fe ≤ 5 + жорсткість, амоній, окиснюваність > 5 | Комплексна засипка | F63C3 / Clack CI | CTFilter (Ecomix C при окиснюваності > 10) |
| Нітрати > 50 | Видалення нітратів | F63C3 / Clack CI | Resinex NR-1 |
| Кольоровість > 20° | Сорбція кольоровості | F63C3 / Clack CI | Ecosoft CO12 |

- **Колона** — найменша, що тягне пікову витрату й дає регенерацію не частіше ніж раз на 4 доби.
  Витрата: за санвузлами (1 → 1,0; 2 → 1,5; 3 → 2,0 м³/год…) або за мешканцями, береться більше значення. Можна задати вручну.
- **Засипка** — фасування підбираються під об'єм колони (наприклад, 62 л = 2×25 + 1×12).
- До ступенів із сіллю додаються сольовий бак під колону і 2 мішки солі. Для колон від 1035 додається кварцова підкладка.
- Попередження з'являються, коли pH < 6,5 або > 9, Fe > 10 чи Mn > 2, система перевантажена або ціни бракує.

Пороги — у `LIMITS`, розміри колон і продуктивність — у `COLUMNS`.

## Каталог і ціни (`lib/catalog.js`)

Перенесено з Sheet «WaterHub — довідник: колони, клапани, засипки» (65 позицій, SKU `WH-…`).
**Важливо:** у довіднику немає цін на колони, клапани Clack, бак 150 л, NR-1 та частину вугілля.
Доки їх немає, кнопка швидкого замовлення в чаті не з'являється: ціни вводяться у формі.
Заповніть `price` у `lib/catalog.js`, і замовлення з чату створюватиметься в один дотик.
SKU мають збігатися з артикулами товарів у KeyCRM, тоді позиції прив'яжуться до каталогу CRM.

## Запуск (Vercel, ~10 хв)

1. Створіть бота в @BotFather і отримайте токен.
2. У KeyCRM: **Налаштування → API** → створіть ключ.
3. Імпортуйте репозиторій у Vercel і задайте змінні середовища з `.env.example`:
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` (будь-який випадковий рядок);
   - `ALLOWED_USER_IDS` — Telegram ID менеджерів (бот показує ID, якщо доступ закрито);
   - `KEYCRM_API_KEY`, `KEYCRM_SOURCE_ID`, `KEYCRM_DOMAIN`;
   - `KEYCRM_MANAGER_MAP` — відповідність `telegramId:keycrmManagerId`, щоб замовлення падало на того менеджера, хто його створив.
4. Дізнатися ID джерела: `KEYCRM_API_KEY=... npm run keycrm:sources`.
5. Підключити вебхук і кнопку меню:
   `TELEGRAM_BOT_TOKEN=... TELEGRAM_WEBHOOK_SECRET=... npm run set-webhook https://<проєкт>.vercel.app`

Self-hosting (VPS, Render): `npm start` (порт `PORT`, за замовчуванням 3000), далі той самий `set-webhook`.

## Структура

```
api/telegram.js   вебхук бота (текст → підбір → кнопки, створення замовлення)
api/select.js     POST: розрахунок підбору для Mini App
api/order.js      POST: замовлення з Mini App (перевірка підпису initData Telegram)
api/catalog.js    GET: каталог для додавання позицій
lib/selector.js   логіка підбору
lib/parser.js     розбір вільного тексту менеджера
lib/keycrm.js     клієнт KeyCRM (POST /order)
lib/catalog.js    каталог WaterHub
public/index.html Mini App
server.js         сервер для self-hosting
```

Імпорт каталогу в KeyCRM (група «Водопідготовка», підгрупи, ціни 100/200): `node scripts/keycrm-import-catalog.js` — перегляд, з `--apply` — створення. Повторний запуск пропускає наявне.

Тести: `npm test`.

## Безпека

- Ключі лише в змінних середовища, у коді їх немає.
- Mini App перевіряє підпис Telegram `initData`, а вебхук — `secret_token`.
- Назви товарів і одиниці виміру беруться з каталогу на сервері, з форми приходять лише SKU, кількість і ціна.
