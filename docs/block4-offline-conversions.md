## ⏳ Потрібно зробити на сайті: вставити код у форму лендінгу

Без цього кроку в ClickIDs буде gclid, але не буде GA client_id, тож GA4 продажі не отримуватиме. Google Ads працюватиме і без цього, бо використовує gclid і хеш телефону.

**Що зробити:** у HTML-блоці лендінгу `/analiz-vodi-analiz-vodi-irpin` в обробнику відправки форми **перед `fetch(WEBHOOK_URL, …)`** додати рядок `Object.assign(data, whGaIds());`, а сам фрагмент нижче вставити в той самий `<script>`.

```html
<script>
function whGaIds() {
  function ck(n) { var m = document.cookie.match(new RegExp('(?:^|; )' + n.replace(/[.$?*|{}()\[\]\\\/\+^]/g, '\\$&') + '=([^;]*)')); return m ? decodeURIComponent(m[1]) : ''; }
  var ga = ck('_ga');                                   // GA1.1.1234567890.1700000000
  var cid = ga ? ga.split('.').slice(-2).join('.') : '';
  var gs = ck('_ga_GTT8T7SMQJ');                        // GS1.1.1700000000.5.1… або GS2.1.s1700000000$o5…
  var sid = '';
  if (gs) { var m2 = gs.match(/^GS2\.\d\.s(\d+)/); sid = m2 ? m2[1] : (gs.split('.')[2] || ''); }
  return { ga_client_id: cid, ga_session_id: sid };
}
</script>
```

**Як перевірити:** відправити тестову заявку з лендінгу. У вкладці ClickIDs має з'явитися рядок, у якому заповнені колонки `ga_client_id` (формат `1234567890.1700000000`) і `ga_session_id`.

## ⚠️ Перевірити в Google Ads (робить власник)

1. **Чи налаштоване завантаження з таблиці.** Перейдіть у «Інструменти → Конверсії → Завантаження → Розклади». Має бути розклад з джерелом «Google Таблиці» на цю таблицю, вкладка `Untitled`.
   - Шаблон Google для офлайн-конверсій вимагає колонку **Conversion Name**, а в поточній таблиці її немає.
   - Якщо розкладу немає або він видає помилки, конверсії в Google Ads досі не потрапляють. Тоді потрібно створити дію-конверсію «Продаж (офлайн, KeyCRM)» типу «Імпорт → Кліки» і налаштувати розклад. Я можу підлаштувати колонки таблиці під шаблон, щойно буде відома назва конверсії.
2. **Який акаунт робочий:** `759660328` (стоїть у GTM) чи `11319035143` (записаний у Notion).

## Що це дасть
- Google Ads отримуватиме реальні продажі, а не лише заявки. Для лідів з лендінгу — за gclid з точною атрибуцією до кампанії, для решти — за хешем телефону (Enhanced Conversions for Leads).
- У GA4 перестануть з'являтися фейкові користувачі `keycrm.*` з джерелом `(not set)`.
